Stops duplicate sound on the mini, adds relative mouse control for first-person games, and adds full-panel MacBook Pro resolutions including the area beside the notch.

Update **both Server and Client to 0.1.5** using **Check for Updates…**. Press **Control–Option–S** for Session Controls.

- **Mute mini speakers:** enabled by default under Audio. The mini's default output is muted once audio is forwarded to the MacBook. Its previous mute state is restored when forwarding stops, the connection closes or Server quits. Volume stays unchanged; turn the option off to hear both Macs. Output changes are handled, existing mute settings are preserved, and owned changes are recorded for recovery after a Server crash. Some external outputs do not support software mute; select the mini's built-in speakers or mute that output directly if an error appears.
- **Game Mouse:** focus the game on the mini, enable Game Mouse in View or Session Controls → Session, then click the viewer. It hides and locks the local pointer and sends movement deltas for looking around. **Control–Option–G** toggles it and **Control–Option–Esc** releases the pointer. Adjust sensitivity in Session Controls; turn it off for desktop/menu navigation. Focus loss, Space changes and disconnects restore normal pointer movement. The Stanley Parable needs a live compatibility check; games requiring hardware-only raw mouse input may ignore injected events.
- **Full panel resolutions:** choose **1512 × 982 · 14″ full screen · HiDPI** or **1728 × 1117 · 16″ full screen · HiDPI** to include the top strip beside the notch. Reopen the updated Server to recreate its virtual monitor. Transparent Mode fills the viewer's safe area and Client opts out of camera compatibility scaling. The physical notch still obscures content behind it. The existing 16:10 choices remain available. The 16-inch stream is downsampled within the 2160p video limit.

New controls indicate when the connected Server needs an update. Connection keys and saved scaling are preserved. Apple High Performance Screen Sharing can still conflict with the virtual monitor; use Standard Screen Sharing during setup.

Both apps are compiled and signed locally, then notarized by Apple. Sparkle verifies the signed update feeds and archives. GitHub Actions remains disabled.
