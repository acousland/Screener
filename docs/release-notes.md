Pair your MacBook once, then create and manage the mini's screen and update Server from the Client.

Update **both Server and Client to 0.1.6** using **Check for Updates…** or the downloads below. Server needs this version once before future updates can be initiated remotely.

- **Pairing:** choose Copy Pairing Invitation on the mini, then Paste Pairing Invitation in Client. Existing connection keys still work. Pairing uses the full random 256-bit key over mutually authenticated TLS; successful pairings are saved in Keychain and appear in Paired minis. New Key on Server revokes all prior invitations and saved keys.
- **Create and start from your MacBook:** Connect & Start Screen creates a virtual monitor if needed and starts viewing. Set Up Server Without Viewing lets you create/select a screen, choose resolution and change mini preferences first. Server listens independently of virtual monitor creation and Screen Recording permission, so setup errors remain accessible through the secure connection.
- **Mini preferences:** enable Open Server at Login and clipboard sharing from Client. Permission status and pending Login Items approval are shown. Open on Mini opens its settings; macOS approval still requires interaction on the mini, directly or through Standard Screen Sharing.
- **Stop Viewing:** stop capture without disconnecting setup or removing the virtual monitor. Held input and mini audio muting are released. Start Screen resumes with current video/audio settings.
- **Update & Restart Server:** in Session Controls → Server Updates, initiate installation of the latest compatible signed release. Download/preparation progress appears on the MacBook. Server stops capture and restores audio before Sparkle relaunches it; Client automatically reconnects, checks the new build and resumes viewing. A writable Applications installation is required; administrator approval may still need to happen on the mini.

Server must be installed and running in the mini's logged-in desktop session. This does not provide app launch after quitting, powered-off Mac startup or FileVault/login-window access. Older Servers continue to stream normally, with management controls available after updating. Existing connection keys, display scaling and media preferences are preserved.

55 automated local tests pass. Both apps are compiled and signed locally, then notarized by Apple. Sparkle verifies the signed feeds and archives. GitHub Actions remains disabled.
